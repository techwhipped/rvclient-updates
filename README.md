# RVClient Voice Chat — Updates

This repository hosts **released builds** of the RVClient proximity voice-chat mod for
Rumbleverse. It contains **no source code** — only the packaged release zips, published
as GitHub Releases.

## Install

Download the latest `RVClient-VoiceChat-vX.Y.Z.zip` from the
[Releases](../../releases) page and follow `README-VOICE.txt` inside it.

## Automatic updates

Recent builds check this repository on launch and offer to update themselves. Only
releases tagged `vX.Y.Z-stable` are offered — test builds are published under other tags
and are ignored by the updater. You can disable the check with `auto_update=0` in
`RVVoiceConfig.txt`.

## Linux (coming soon)

rVclient is coming to Linux: its own Linux launcher - the same pages, look and account as the Windows
launcher - and a one-file installer that sets up Proton (no Steam needed) next to **your own copy** of the
game. It is being tested now; the release is announced in the RVClient Discord.

Each release carries the Linux launcher as `rvclient-launcher-linux.tar.gz`, next to the Windows files. The
Linux launcher updates itself from it, the same way the Windows launcher does.
